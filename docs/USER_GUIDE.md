# MshTV 使用与开发指南

MshTV 是面向 AI 影视创作者的独立多媒体素材管理工具，核心是自由画布、图片/视频/音频管理、本地文件夹监控和影视镜头分组。采用 Windows 本地后端 + 跨设备 WebUI 架构，不依赖 AI 生成工具，不包含模型调用、节点流程或视频剪辑。

## 本轮可用功能

- WebUI 默认浅色。工作空间和画布右上角的日月图标可切换浅色或深色，当前浏览器会记住选择。浅色主题采用白色工作台、银灰控件和轻微的卡片阴影。
- 浅色主题的按钮使用纯色底和细线框，界面灰度固定为 7%。
- 工作空间和画布右上角共用「设置」入口，提供局域网访问、存储与维护及 HDR 开关。局域网访问和 HDR 均默认关闭。开启 HDR 后，浅色主题的常规 HDR 亮度为 25%，深色主题常规选中光使用 SDR。开启 HDR 后可在两种主题使用闪光弹模式，选中高光持续为 100%。关闭 HDR 会同时关闭闪光弹模式。设备不支持时使用 SDR 光晕。HDR 两个开关由当前浏览器记住。
- 画布左侧是素材库，右侧是可折叠的属性面板。深浅主题的卡片、图片和分组使用一致的圆角，浅色主题以银灰分栏和细银灰描边衬出浅灰画布。素材缩略图和来源按钮采用清晰的银灰边框，来源按钮悬停时显示底部暖光。
- 普通模式下，选中的卡片或分组会上浮一点。浅色主题使用淡暖黄光晕，深色主题使用亮度更低的琥珀暖光。可直接拖选中项的角点缩放，文字备注和分组也可拖边缘中点。性能模式使用描边和可见手柄。
- Mac 默认可双指滑动平移，捏合围绕指针缩放。鼠标模式用滚轮缩放。两种模式都支持按住空格拖动、适应全部和重置视角，鼠标也可用中键平移。
- 当前浏览器会自动记住每张画布最后的平移位置和缩放比例，重新打开或刷新时恢复。
- 在画布顶部工具栏右侧的「快捷键」中，可切换「滚动方式」。偏好保存在当前浏览器，Ctrl 或 ⌘ 加滚动可缩放。
- 添加离线示例图片、视频/音频占位卡片；移动、等比调整尺寸、命名、删除。
- 框选、Ctrl 多选、批移动、基础分组/解组；备注双击原位输入，素材名称双击原位编辑。
- 分组板独立保存位置和长宽。拖动板子带动成员，拖动组内卡片仅移动该项。双击分组标题可原位重命名，Enter 确认，Esc 取消。分组板可自由改尺寸，卡片松手时按中心位置自动加入或退出分组。
- 文字备注可独立调整宽高，拖动边框或角点仅改变文本框，正文固定 16px 并随宽度换行；画布缩放仍正常作用于整体视图。
- 画布中的备注仅显示正文，不再显示顶部标题。
- 备注新建或已有都需双击正文进入编辑，单击仅选中；图片、视频、音频卡片底部名称双击即可直接修改，无弹窗。
- 备注编辑时可选中文字，使用小工具条加粗、斜体、下划线、标红或清除格式；可组合使用，字号仍固定为 16px。
- 撤销/重做（本次打开后的最近 60 次操作）。
- SQLite 实际持久化：自动保存、手动保存、重新加载；revision 冲突检测和幂等重试。只有收到后端确认才显示“已保存到本机”。
- 多个 Windows 本地文件夹：首次扫描、启用/暂停、主动重扫、移除配置；重启后恢复监控。
- 图片/视频/音频索引，文件名搜索、类型筛选、添加/修改时间排序，每页 50 项、最多 200 项；新增文件实时通知，无需刷新页面。
- 图片缩略图和较大预览。视频支持素材库静音悬停、画布内播放和拖动进度。音频支持素材库及画布内试听、波形和进度控制。
- 从素材库拖入画布，释放位置按当前平移/缩放换算；同一素材可重复引用，自动保存后刷新恢复。原始文件丢失时保留卡片并提示。
- 素材按来源文件夹分类查看，保留原子目录信息；可删除单个库内素材或整个来源文件夹，原件不变、画布卡片保留为已移除提示。
- 右上角电源按钮保存当前画布后关闭后端；保存失败/冲突时取消关闭，服务停止后显示关闭提示。

启动后打开工作空间首页，已有画布会保留在首页。素材原件保持只读。Windows 可使用安装版或源码启动方式。

## 工作空间与素材库

- 双击工作空间首页的空白处，从菜单选择「新建画布」或「新建画布组」。在组内双击空白处可新建这组的画布。顶部也有新建按钮。独立画布各用自己的素材库，同组画布共享素材和监控目录。
- 点画布封面打开编辑器。编辑器左上角的「工作空间」会先确认当前修改已保存，再返回首页。首页可以搜索名称、按编辑时间排序和置顶。置顶的组内画布也显示在首页。
- 鼠标悬停时，画布卡和画布组卡会轻微上浮并亮起底部暖光。页面按钮以更轻的底光反馈悬停，底色变更用于选中和确认状态。拖动项目时卡片保持在原位。
- 将画布卡片拖到首页的画布组卡片上，目标高亮时松手即可移入。组内画布的「⋯」菜单可直接选择「移出为独立画布」。重命名、复制和选择移动目标也在「⋯」菜单中。
- 点击画布或画布组旁的垃圾桶，原位显示确认，再点同一位置移入回收站。按 Esc 或点别处可取消。回收画布组会同时隐藏组内画布并暂停共享监控。右上角「回收站」可恢复，原本已单独回收的画布须单独恢复。
- 回收站里，点卡片上的「彻底删除」后，再点原位置确认。彻底删除画布组会同时删除组内所有画布，包括之前单独回收的画布。彻底删除后无法从回收站恢复，磁盘上的原件与导入副本保留。

| 操作 | 素材与监控处理 |
|---|---|
| 独立画布移入组 | 合并素材记录与监控来源。同一目录沿用目标组现有设置。 |
| 组内画布移到另一组或移出 | 带上该画布正在引用的素材。目标组继续使用自己的监控配置，移出后的独立库可以另设监控。 |
| 复制独立画布 | 新画布获得独立库，带上该画布正在引用的素材。 |
| 复制组内画布 | 副本留在原组，使用原组的共享库。 |

复制和移动保留画布布局、内部素材分组及备注。活动画布引用的可用素材随明确的移动操作一并带入。多个素材库可以监控同一个目录，每个库单独决定是否递归和是否只收录新增文件。同一路径的媒体元数据与预览缓存可以复用。

首次运行新版会先备份 SQLite，再把已有「自由画布」及其素材与监控迁入独立画布。旧数据库没有记录画布创建或编辑日期，首页初始显示迁移时间。备份和回退步骤见 [工作空间迁移](ARCHITECTURE.md#工作空间迁移)。

## 工程文件与存储维护

- 画布卡片的「⋯ → 下载工程文件」保存当前已确认版本为 `.mshtv`。文件包含布局、备注、分组和素材 ID。工作空间顶部「导入工程」会在本机保存的原素材库中校验引用，并创建新的独立画布。原工程使用的素材索引随整库备份保留，换机时可先恢复该备份。工程文件导入限 32 MiB。
- 右上角「设置 → 存储与维护 → 存储设置」显示当前工作目录，可打开该目录，检查 SQLite 完整性、素材引用及空间用量。外部素材大小按索引估算。确认清理仅处理应用生成的预览图、视频封面及波形，需要时会重新生成。
- 「更改工作目录」可选择 Windows 上已有的空文件夹。保存设置后关闭后端，再双击 `start.cmd`。重启时复制并校验数据，成功后切到你选定的目录。原数据目录保留，失败则继续使用原目录。
- 「备份与恢复」提供独立入口，可选择 Windows 上的保存位置。备份和恢复也在下次启动时执行。备份包含所有画布、监控配置及应用存储的导入副本，监控原件继续保存在原目录。恢复请选择 MshTV 创建的整库备份，校验通过后会切到恢复生成的新工作目录。
- 中途断开可能留下 `.partial` 文件夹，可在 MshTV 关闭后按名称核对并手动清理。

## 添加素材与监控文件夹

1. 启动后点击左侧素材库标题旁的文件夹按钮。
2. 输入 **Windows 后端电脑**上的完整本地目录，例如 `D:\影视素材\项目一`，点击“添加目录”。这不是浏览器设备的文件夹；不支持网络共享、链接/junction 或与应用数据目录重叠的路径。
3. 添加前可选择“包含子文件夹”和“只计入新文件”。默认包含子文件夹、收录已有文件。正在写入的文件显示“等待文件完成 / 分析中”；就绪后可拖入画布。以后放进该目录的媒体会自动入库，不会自动放入画布。
4. 修改已有目录须使用“已添加的文件夹”中对应目录下面的选项，那里会显示实际扫描范围；“添加新文件夹”上方的开关不修改旧目录。重复提交已有路径且选项不同时会提示，不会静默沿用旧设置。也可暂停/启用、重新扫描或移除配置；暂停仍可手动重扫，已有素材仍可预览。
5. 左侧选择来源文件夹查看对应素材，搜索/类型/排序/分页作用于当前文件夹；“全部素材”跨来源查看。素材行显示来源及原子目录，悬停可看完整来源位置。
6. 拖动素材行到画布，在释放处创建卡片。选中后仍沿用原有移动、等比缩放、命名和分组操作；双击画面预览，双击底部文字改名。

当前画布引用的素材会在素材库缩略图右上角显示绿色小勾。删除同一素材的最后一张画布卡片后，小勾会消失。

从资源管理器直接把图片、视频或音频拖进页面，MshTV 会自动添加到素材库和画布。画布区域按释放位置放置，其他页面区域从画布可见中心放置。一次最多拖 20 个文件，单文件上限 32 GiB，多选按顺序排开并可一次撤销画布放置。

唯一匹配已有素材时复用其引用。新文件会流式传给本机后端，副本保存在应用数据目录的 `imports` 中，并显示在素材库的“拖入导入”下。导入后至少保留 5 GiB 磁盘空间。库内移除沿用软删除，应用副本保留供再次导入复用。

同卷重命名和在已登记目录间移动会利用 Windows 文件标识保留素材 ID。移到未登记目录或删除后显示缺失。跨卷移动按新文件处理。目录离线与单文件缺失分别提示，素材库和画布中的删除操作均保留磁盘原件。

监控选项：

- **包含子文件夹**：关闭后只自动发现当前目录的文件，手动重扫、删除来源后重新添加也遵守此范围。以前仍在库内的子目录素材和画布卡片保留，标示“已收录 · 当前不监控子目录”，不代表刚刚扫描加入。
- **只计入新文件**：开启时先记录当前已有文件，状态显示“监控中”后再放入新文件；初始化期间出现的文件可能被作为已有文件跳过。旧文件不会入库，修改或可识别的改名也不算新增；后来复制进来的旧日期文件仍属于新增。不会清除已入库的素材。
- 重启、暂停/恢复和手动重扫保留上述选择及已有文件记录。关闭“只计入新文件”会补扫范围内的已有文件；在此模式下改变子目录范围，会重新记录当时尚未入库的文件，完成后接收新增。

## 素材库整理与删除

点击素材或来源文件夹的删除按钮后，原位显示“确认删除”。再点一次执行，切换焦点或按 Esc 可以取消。

- 素材行右侧垃圾桶：确认后从素材库移除该素材。磁盘原件不删除，已有画布卡片保留并显示“素材已从素材库移除”；重扫、重启及可识别改名不会自动加回来。
- 来源文件夹旁垃圾桶，或管理窗口的“删除文件夹”：移除这个来源及其全部库内素材并停止监控，不删除磁盘文件夹/文件。这里的文件夹按已登记来源分组，内部子目录作为素材位置显示，不是磁盘文件管理器。
- “移除配置”仍只停止监控并撤销访问，保留库内记录，与“删除文件夹”不同。
- 恢复已删除来源可重新添加同一路径；恢复某个仍在监控来源中的已移除素材，可先移除配置再重新添加。重新添加时只恢复所选扫描范围内的已移除条目，并保留原 ID；勾选“只计入新文件”不会恢复旧条目。未勾选包含子目录时，已删除的子目录条目不会重新出现。当前没有单项回收站或批量选择删除。

## 从网页关闭后端

工作空间和画布页的右上角都有电源按钮。工作空间选择「确认关闭后端」。画布页选择「保存并关闭后端」，当前画布保存成功后才发送关闭请求。后端关闭会停止监控和媒体任务，并断开所有页面，请先保存其他页面的修改。页面显示「后端已关闭」后可关闭浏览器，再次使用时运行 `start.cmd`。

## 本地媒体工具与格式限制

开发版可使用 FFmpeg / ffprobe **9.0.1-full_build-www.gyan.dev**。后端只用它们分析元数据、提取单张封面及生成图片 WebP，不做视频/音频转码。依次在 `MSHTV_FFMPEG_DIR`、后端输出目录的 `media-tools`、PATH 查找，启动后按 `src/MshTV.Server/media-tools.lock.json` 的 SHA-256 校验；不下载工具。换目录或安装工具后需要重启后端。

新机器须自行准备清单匹配的本地工具，或在审核版本/许可证后更新清单并重新构建。缺失或校验不匹配时仍保留索引并允许浏览器原生预览，但封面/时长可能不可用；配置好工具并重启后，点击“重新扫描”重试失败项。开发仓库不附带这些二进制，发布前还需完整许可证清单与打包验证。

优先使用 JPEG/PNG/WebP、H.264/AAC MP4、MP3/WAV 等当前浏览器兼容媒体。无法播放的素材仍可入库和摆放，预览会提示原因并提供原文件下载。

- 普通模式下，素材库视频封面悬停约 300 毫秒，播放最多约 6 秒的静音预览，移开后恢复封面。两种模式都可以点击封面打开大播放器。
- 素材库音频点击三角图标试听。画布上的图片框和视频框会按画面比例自动适配，可拖角点缩放。单击视频画面可播放或暂停，进度条位于卡片下方。音频使用卡片中央的播放图标，可用其播放控件拖动进度。拖卡片画面或标题可移动，播放器上也可使用当前画布的滚动方式。视频封面在合适的显示尺寸使用最长边 1024 的预览。
- 每个页面同时播放一路。切换素材、离开视口或页面隐藏时释放行内播放器。本次打开期间再次播放同一画布卡片，会尝试从上次进度继续。刷新后按已保存的素材引用恢复卡片，播放需手动开始。
- 音频波形首次试听时流式生成，磁盘缓存按素材版本复用。每条至多 512 个峰值，后端同时生成一路，支持最长两小时，单次处理上限 25 秒。波形不可用时仍可使用浏览器原生试听。

图片缩略图最长边 256，清晰预览最长边 2048，小原图按原有尺寸生成。画布在卡片显示较大时优先为视口内最多两张图片加载清晰预览，选中的卡片优先，也可以双击图片单独查看。升级后，库内未生成完整预览且符合像素限制的图片会在后台自动重试。超过 1 亿像素的图片仍保留在库中，后台跳过预览生成。

派生图缓存位于应用数据目录的 `media-cache`。单工具 25 秒超时，低于 5GiB 空闲暂停生成。缓存默认预算 20GiB，后台逐批淘汰并在访问缺失缓存时重建。尚未进行十万文件实际扫描和磁盘压力验收。

### 性能模式

顶部右侧的「性能模式」开关可即时切换。关闭时为**普通模式**，后台最多同时分析并生成 6 份素材预览，保留原来的悬停预览和画布预加载范围。开启时后台最多处理 2 份，视频封面悬停时保持静止，画布缩小视野外的预加载范围。两种模式使用同样的图片清晰度、手动播放和音频试听。

网页拖入仍按顺序接收文件，开关控制后续的后台分析和预览生成。切换后，已经开始的分析会完成；之后按新上限领取任务。选择保存在本机，重启后自动恢复。

## 按画布分组导出

1. 单击分组板选择整组，按住 Ctrl 单击其他分组板或卡片可追加选择。属性栏的“选中组内元素”可把所选分组转换为卡片选择，便于批量移动或调整。
2. 点击顶部“导出选中内容”或“导出整个画布”。用“选择文件夹”打开运行 MshTV 的 Windows 电脑上的系统选择窗口，也可直接填写路径。选择素材来源与应用数据之外的已有目录，再填写新文件夹名称。浏览器会记住最近使用的目标目录。
3. 点击“开始导出”。MshTV 保存画布后按该版本的分组复制原文件，未分组的素材进入“未分组素材”。同组重复引用合并，跨组引用分别复制。空分组、备注、示例图和占位卡不计入文件数量。
4. 导出期间可选择“后台运行”继续整理画布，也可取消。完成后查看成功数、失败数、目标路径和导出报告，并可在 Windows 资源管理器打开结果。

同名目录和文件会添加编号。缺失、离线、未就绪或无法读取的文件会记录失败原因，其余素材继续复制。取消会保留已完成文件并清理正在复制的临时文件。进程异常退出时，以目标目录的报告为准，可能留下标为 `.partial` 的临时文件，重新导出会新建目录。

## 复制原文件到 Windows 剪贴板

1. 在 Windows 后端电脑上用 `start.cmd` 打开 MshTV，直接使用本机页面。
2. 在画布选中媒体卡片或分组。按住 Ctrl 可追加选择，选中分组会包含其全部媒体成员。
3. 按 Ctrl+C，或点击顶部工具栏的“复制文件”。看到成功提示后，在 Windows 桌面空白处或资源管理器的目标文件夹内按 Ctrl+V。

同一个原文件只列入一次。文字、示例和占位卡片会计入略过提示，缺失或无法读取的素材会列出原因，可用文件仍可粘贴。通过浏览器拖入并托管的素材使用应用保存的原始内容副本，Windows 资源管理器粘贴时采用导入时的有效文件名。

功能需要同一 Windows 用户的活动交互式桌面和直连本机页面。Windows Service、代理访问与其他设备可使用导出或下载。其他软件须支持 Windows 文件列表粘贴。编辑备注、改名或选中网页文字时，Ctrl+C 使用原有的文字复制行为。

## Windows 安装版

1. 从 [GitHub Releases](https://github.com/mushanghan/MshTV/releases/tag/v0.9.3) 下载并运行 `MshTV-Setup-0.9.3-win-x64.exe`。选择程序目录和项目数据目录，后者必须在程序目录之外。安装适用于 Windows 10 21H2 及以上的 x64 环境。
2. 从桌面或开始菜单打开 **MshTV**，在「总览」点「启动 MshTV」。通过健康检查后，程序会用默认浏览器打开工作空间。窗口为无边框 16:10，可拖动顶部栏、最小化或关闭。关窗默认留在托盘，可在「维护」取消这一设置。右键托盘图标查看服务状态，启动后菜单会显示打开工作空间、停止和重启选项。关浏览器后，文件监控会继续运行。停止、重启或退出前，请保存其他页面的修改。
3. 「维护」中的「检查环境」会核验安装文件、数据库和媒体组件，并验证后端能否启动。「修复运行目录」可补建缓存目录。安装文件损坏时，运行同版或更新的安装包修复。启动后可检查用量、清理派生缓存或进入现有的局域网和存储设置。

启动管理中心默认浅色，右上角可切换深浅主题。托盘菜单使用同一套配色，可用按钮悬停时轻微抬升，底部显示纯色暖黄短线。主题按钮采用微软雅黑 UI，日月图标单独绘制。启动器主题保存在本机，网页主题由各浏览器记住。

安装器默认识别 `%LOCALAPPDATA%\MshTV\data`。如果旧版通过 `MSHTV_DATA_DIR` 使用其他位置，请选原目录，使画布和媒体引用直接接续。需要换盘时，在启动管理中心打开「备份与迁移」，先创建整库备份，再使用「更改工作目录」。这两项任务分别于重启时执行，迁移完成并校验后才切换，原目录仍保留。

官方安装包自带 .NET 桌面和 ASP.NET Core 运行时、SQLite、WebUI、FFmpeg 9.0.2 和 ffprobe。可在离线环境生成封面、波形及缩略图。媒体组件的许可证、源码及构建参数见 [Windows 内置媒体工具](FFMPEG.md)。

**手动升级与卸载。** 用新安装包覆盖当前程序目录，项目数据保持原位。Windows「设置 → 已安装的应用」可卸载，卸载会停止由管理中心启动的后端并移除程序和快捷方式，保留项目、应用缓存与原始素材。这一版没有在线更新、自动程序回退或安装包签名。

维护者在仓库根目录使用 `pwsh -File tools/build-windows.ps1` 构建。构建需要已锁定的 .NET SDK、Node.js/npm 和 [Inno Setup 6.7.3](https://jrsoftware.org/isdl.php)。用 `-Compiler` 指定 ISCC 路径，用 `-Version` 设置三段版本号，用 `-MediaKit` 指定已校验的媒体工具目录。安装包和 SHA-256 文件输出到 `dist/windows`。包内 `licenses/THIRD-PARTY.txt` 列出实际依赖。 [媒体工具构建说明](FFMPEG.md)

测试时用 `-TestPackage` 构建独立注册的 MshTV-QA，再运行 `node tools/windows-install-smoke.mjs <QA安装包> [新版QA安装包] [旧版后端DLL]`。测试占用 5188，并拒绝接管运行中的本机 MshTV。数据库、程序和素材全部在隔离目录。

## 源码启动

需要 Node.js 24 LTS、.NET SDK 10.0.403（或同 feature band 后续补丁）。可以使用已安装的 SDK，或把 SDK 放入项目的 `.tools/dotnet`。

**双击根目录 `start.cmd`**。这是源码测试入口，可直接体验最新改动。脚本构建前端、将静态资源复制到后端、按仓库锁定的 Windows x64 配置构建并启动服务，然后自动打开：

[http://127.0.0.1:5188](http://127.0.0.1:5188)

保留启动窗口运行，按 Ctrl+C 停止。重启仍读取同一数据库。首次在新机器运行会执行 `npm ci`（需要联网）；依赖已安装后构建和使用均可离线。若缺少 SDK，安装上述版本的 [.NET SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)，或通过微软 dotnet-install 脚本安装到 `.tools/dotnet`。

数据默认保存在 `%LOCALAPPDATA%/MshTV/data/canvas.db`，不在项目源码目录。可在启动前设置 `MSHTV_DATA_DIR` 更换应用数据目录；它不是素材目录。不要把数据库放在网络共享或同步盘。启动前需停止上一个后端，5188 端口被占用时脚本会提示。

## 局域网跨设备访问

1. 在 Windows 主机运行 `start.cmd`，本机打开 MshTV。右上角进入「设置 → 局域网访问 → 连接」，勾选启用，选中连接家庭或工作网络的网卡，保存设置。默认局域网端口为 5443，提示被占用时可修改。[打开本机 MshTV](http://127.0.0.1:5188)
2. 保存打开的画布，关闭 MshTV 后端并重新运行 `start.cmd`。回到「连接」页，确认状态为已接受连接，复制面板里的 HTTPS 地址，例如 `https://192.168.1.20:5443`。地址按实际网卡为准。
3. 在主机下载 `MshTV-LAN.cer`，通过可信方式交给另一台设备。核对文件的 SHA-256 指纹与主机面板一致，再在设备上信任该证书。Mac 可在「钥匙串访问」导入并设置信任；iPhone/iPad 安装后还需在「设置 → 通用 → 关于本机 → 证书信任设置」启用对应证书的完全信任；Windows 可导入当前用户的「受信任的根证书颁发机构」。[Mac 证书信任](https://support.apple.com/en-ca/guide/keychain-access/kyca11871/mac) · [iPhone/iPad 证书信任](https://support.apple.com/en-ie/102390) · [Windows 证书存储](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/trusted-root-certification-authorities-certificate-store)
4. 在主机的「局域网访问 → 设备」页生成一次性配对码。在另一台设备的浏览器打开显示的 HTTPS 地址，输入设备名称和配对码。配对码有效 5 分钟，每个设备用一个新码。配对后请继续使用同一个浏览器和地址，重新打开网站或重启 MshTV 都能直接连接。成功连接时会续存浏览器凭据，有效期为一年。

退出设备连接、在主机撤销访问、清除浏览器站点数据或修改主机的局域网设置后，需要重新配对。从旧版本升级后也需要配对一次，才能保存设备。

远程设备可以管理工作空间和编辑画布、浏览媒体并下载授权原件。Windows 主机本机负责添加及修改监控目录、批量文件夹导出、原生文件剪贴板、存储维护和关闭后端。远端编辑使用同一 SQLite 画布版本，冲突会明确提示。断网时保留当前页面里的未确认修改，恢复网络后点击「重试连接 / 保存」，有版本冲突时先核对当前内容再重新加载。

主机面板的「测试主机连接」验证监听与证书。如果主机测试通过但另一台设备仍超时，核对所选网卡，检查访客 Wi‑Fi 的设备隔离、跨子网的路由及 Windows 私有网络入站设置。若需要放行，只为所选 TCP 端口和所需的私网来源配置规则。MshTV 不改动系统防火墙或路由器。支持单个私网 IPv4 监听地址，IP 变化时重新保存设置并将新证书交给设备。关闭局域网会即时撤销远端访问，重启后解除监听。

如果浏览器提示证书不受信任，请在设备上核对访问 IP、证书指纹、信任设置和系统时间，完成证书信任后再配对。

## 操作与数据提示

点击左侧图卡添加图片；拖动卡片移动，媒体卡片选中后拖动四角等比缩放；文字备注支持边框和角点自由调整宽高，字号保持固定。空白处拖动框选，Ctrl 增减选择；Ctrl+G 分组，Ctrl+Shift+G 解组；N 新建备注；Ctrl+Z 撤销，Ctrl+Shift+Z 重做；Delete 删除；F 适应全部，Ctrl+S 保存。顶部“快捷键”提供完整说明，macOS 可用 ⌘ 代替 Ctrl。

保存失败会暂停新编辑并保留当前页面中的修改，可重试。冲突时可保留当前页面核对，再确认重新加载。**未确认修改仅留在页面内存，关闭或刷新可能丢失**。离线队列恢复和每日备份尚未实现。

分组板操作：多选卡片后 Ctrl+G 创建；拖动板子的标题或空白处移动整组；点击板子后拖动边框或角点自由调整长宽，内容不随之缩放。拖动卡片时仍可 Ctrl 多选；松手以中心点判断所在分组，分组重叠时取最上层。空分组板会保留，删除或解组只移除板子并保留内容。旧分组首次打开会自动补出初始尺寸。

原位编辑：备注双击正文进入输入，Enter 换行，Ctrl+Enter 结束输入；素材名称 Enter 确认。点击外部也会结束编辑；Esc 恢复本次编辑前的文字。输入停顿后自动保存，一次连续编辑可一次撤销。备注编辑时拖动文字会选取文本，拖动卡片边缘可移动备注。命名只改变画布显示名称，不改磁盘文件名。

备注强调：双击后选中要突出的文字，点击浮动工具条的 B、I、U、红色 A；再次点击可取消该样式，橡皮按钮清除选中部分的全部样式。Ctrl+B/I/U 也可使用，Ctrl+A 后可设置整段。样式随正文自动保存，结束编辑后可整体撤销；Esc 同时恢复本次文字和样式。已有备注默认无样式。此次强调功能增加了后端样式字段，请关闭旧启动窗口并重新双击 `start.cmd`，再刷新页面。

```powershell
& ./.tools/dotnet/dotnet.exe build src/MshTV.Server/MshTV.Server.csproj -p:RestoreLockedMode=true
cd apps/web
npm.cmd run build
npm.cmd test

```

构建后端前先停止正在运行的后端，避免 Windows 锁定可执行文件。端到端测试使用专用端口 5193/5198 和 `.data/e2e-*` 独立数据库，不能指向日常数据库。

验证结果见 DEVELOPMENT_PLAN.md 最近的任务记录。素材测试会用本地 ffmpeg 生成自有 PNG/MP4/WAV。`node tools/library-restart-smoke.mjs` 验证重启与离线恢复（5200 端口）；`node tools/shutdown-smoke.mjs` 验证网页关闭、保存失败阻止关闭及删除状态恢复（5201 端口）。`node tools/launch-library-smoke.mjs` 验证实际启动脚本及生产页面（5188 端口）。这些脚本遇到占用端口均拒绝操作，使用新建隔离数据库/自有素材；不得指向日常数据或真实素材。

`node tools/lan-smoke.mjs <后端 DLL>` 使用隔离数据，要求本机存在私网 IPv4 网卡、Edge、FFmpeg。它校验真实 TLS 信任链、媒体 Range、SignalR、编辑保存和撤销。浏览器进程只对本次测试证书做公钥固定，系统证书信任与实际跨网段连接由设备验收。

工作空间回归使用 `node tools/workspace-smoke.mjs <新版后端 DLL> <迁移前后端 DLL>`，需要同目录包含二进制的配套文件，使用本机 Edge、5276 端口和新建数据目录。脚本验证旧版升级、素材隔离、画布转移、目录离线及恢复，以及故意触发迁移失败后的回退。设置 `MSHTV_TEST_SKIP_NATIVE_CLIPBOARD=1` 可保留当前 Windows 剪贴板内容。

建议手动体验：连续平移缩放、Ctrl 多选与角点缩放、备注中文输入、分组后批移动、保存后关闭重启。Safari、触屏与低配设备上的长时间表现仍待验证。测试启动器时必须设置独立 `MSHTV_DATA_DIR`，`tools/verify-launch.mjs` 额外要求 `MSHTV_VERIFY_ISOLATED=1`，避免改动日常画布。

## 性能基准

在项目根目录运行以下命令。基准使用本机 Edge、FFmpeg、独立端口 5263 和新建的测试数据目录。

```powershell
& ./.tools/dotnet/dotnet.exe build src/MshTV.Server/MshTV.Server.csproj -c Release -p:RestoreLockedMode=true
npm.cmd --prefix apps/web run build
node tools/performance-smoke.mjs src/MshTV.Server/bin/Release/net10.0/MshTV.Server.dll apps/web/dist
```

默认测 100/300 张图、50 图加 20 视频、1000/5000 条素材索引和 5000 文件扫描。命令末尾加 `--full` 测 10 万条素材索引与 1 万画布项。结果写入 `.data/perf-run-*/result.json`，包含首屏、交互帧时间、保存、资源请求和分页内存采样。索引规模与实际分析完成量分别计量。
